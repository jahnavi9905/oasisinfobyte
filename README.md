# 🐍 Oasis Infobyte Python Internship Projects

This repository contains Python projects developed during my **Oasis Infobyte Python Programming Internship**.

The projects demonstrate Python programming fundamentals, GUI development, database integration, input validation, and password generation.

## 📂 Projects

### 1. 🧮 BMI Calculator – Basic

A simple command-line BMI calculator that accepts weight and height as user input, calculates BMI, and classifies the result into different categories.

**Concepts Used:**
- Python functions
- User input
- Conditional statements
- Exception handling
- Basic calculations

**File:** `bmi-calculator-basic.py`

---

### 2. 🧮 BMI Calculator – Advanced

A GUI-based BMI calculator built using Python Tkinter with SQLite database integration and BMI trend visualization.

**Features:**
- Graphical user interface
- User input validation
- BMI calculation and classification
- SQLite database storage
- Parameterized SQL queries
- BMI history and trend visualization
- Matplotlib integration

**Technologies:**
- Python
- Tkinter
- SQLite
- SQL
- Matplotlib

**File:** `bmi-calculator-advanced.py`

---

### 3. 🔐 Password Generator – Basic

A command-line password generator that allows users to choose the password length and character types.

**Features:**
- Custom password length
- Letters
- Numbers
- Symbols
- Input validation
- Error handling

**Concepts Used:**
- Python functions
- String manipulation
- Random character generation
- Exception handling

**File:** `password-generator-basic.py`

---

### 4. 🔐 Password Generator – Advanced

A GUI-based password generator developed using Python Tkinter.

**Features:**
- Graphical user interface
- Custom password length
- Letters, numbers, and symbols
- Input validation
- Password generation
- Copy generated password to clipboard

**Technologies:**
- Python
- Tkinter
- Pyperclip

**File:** `password-generator-advanced.py`

> **Note:** The password generators use Python's `random` module and are intended as programming projects. They should not be considered cryptographically secure password-generation tools.
